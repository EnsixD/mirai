# Обновления mirai

Источник релизов: https://github.com/EnsixD/mirai.

Панель и серверный установщик проверяют подписанный индекс `updates/index.json`
и `manifest.json` релиза. Публичный ключ mirai встроен в Go, Rust и `installer/install.sh`.
Ключ прежнего проекта удалён. Образы выпускаются в `ghcr.io/ensixd/`.

## Первый выпуск

1. Загрузите исходники в `EnsixD/mirai`.
2. В GitHub Settings → Secrets and variables → Actions создайте секрет
   `RELEASE_SIGNING_KEY`: содержимое локального файла `.local/mirai-release-signing.pem`.
   Этот файл исключён из Git; сохраните его резервную копию.
3. Опубликуйте тег `vX.Y.Z.R` на `main`, например `v1.0.0.0`.
   `.github/workflows/release.yml` собирает образы, установщики, подписанный манифест
   и индекс обновлений. Для загрузки образов workflow использует `GITHUB_TOKEN`.

Пока нет опубликованного подписанного релиза, в настройках отображается «релизов ещё нет».
При наличии более новой доступной версии у «Настройки» появляется круглая стрелка
Lucide `RefreshCw`; она также видна в мобильном меню.

## Локальная разработка

Проверка релизов работает и локально. Установка из панели требует серверного
установщика `mirai` и его systemd-служб. Локальная Windows-сборка без Docker
обновляется пересборкой исходников, а не серверным установщиком.
