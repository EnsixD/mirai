# Нативная установка Mirai на Linux

Mirai и mirai-node запускаются отдельными systemd-службами. PostgreSQL и Nginx используются с хоста. Образы Docker и сборочные инструменты на VPS не нужны.

- `/opt/mirai`: проверенные бинарники и VERSION, запись только root.
- `/var/lib/mirai`: данные панели и ноды.
- `/etc/mirai/mirai.env`: настройки и реквизиты БД, режим 0640.
- `/var/backups/mirai`: резервные копии обновлений.
- `mirai-update.path`: запускает обновление по кнопке панели.
- `mirai-update.timer`: проверяет автоматическое обновление ежедневно.

Обновление проверяет Ed25519-подпись manifest.json, SHA256 архива и его содержимое. Перед заменой останавливает службы и сохраняет PostgreSQL. При неудачной проверке здоровья восстанавливает бинарники и базу. Архивы содержат только mirai, mirai-node и VERSION. Нативные релизы публикуются с тегом `native-vX.Y.Z.R` и полем `native.x86_64` подписанного манифеста.

Панель: GOMEMLIMIT=192MiB, MemoryMax=256M. Нода: GOMEMLIMIT=384MiB, MemoryMax=512M. Эти значения ограничивают бюджет процесса, но не гарантируют обслуживание любого количества клиентов: нагрузка зависит от трафика, протоколов и числа соединений.
