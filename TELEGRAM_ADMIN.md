# Администратор в Telegram

Во вкладке **Telegram → Инфраструктура** укажите личный числовой Telegram ID
и нажмите **Сохранить ID администратора**. Подключите токен бота и включите его,
затем отправьте `/start` или `/admin` в личном чате.

Кнопка **Админ** видна только указанному аккаунту. Каждый запрос проверяет ID
отправителя и личный чат. Чат, подключённый прежней ссылкой только для уведомлений,
не получает права управления. Кнопка **Отключить** отзывает права и отключает
этот чат от инфраструктурных уведомлений.

В меню доступны:

- Все пользователи и подписки, страницы по 10 записей и поиск по ID/имени.
- Карточка подписки: тариф, срок, статус, трафик за период и за всё время,
  пакеты и пулы, устройства, контакт и последняя активность.
- Заморозка/разморозка: как отключение пользователя в панели; срок продолжает идти.
- Продление: своё целое число дней, прибавляется к текущему сроку,
  а если он уже истёк — к текущему времени. Продление включает подписку.
- Удаление с подтверждением; ссылка и доступ перестают работать.
- Выдача: Telegram ID получателя → тариф → имя → число дней → подтверждение.
  Получатель должен прежде отправить `/start` боту. Новая подписка автоматически
  привязывается к его аккаунту и появляется в его меню. Сохраняется существующее
  ограничение — не более пяти подписок на Telegram-аккаунт.
- Получение ссылки подписки администратором.

Подтверждение действует 10 минут и выполняется однократно. Изменения записываются
в журнал аудита с Telegram ID администратора. Права вступают в силу по сохранению;
старые сообщения с кнопками не дают доступа после отзыва ID.

## Публичный статус в канале

Это страница состояния серверов для клиентов. Бот публикует и закрепляет одно
сводное сообщение, затем редактирует его при изменениях. Показываются включённые
ноды с заданным публичным именем: «Работает», «Есть проблемы», «Недоступен»,
«Проверяем». Учитывается состояние ноды и её опубликованных инбаундов.

**Канал статуса** — `@username` канала или его числовой ID. Боту нужны права
администратора на публикацию, редактирование и закрепление сообщений.

**Отдельные сообщения о переходе ноды в другой статус** добавляют сообщения
в историю канала при смене состояния: например, сервер стал недоступен,
затем восстановился. Сводка остаётся одной, а история помогает увидеть сбои.
Эта функция необязательна и не управляет подписками пользователей.
